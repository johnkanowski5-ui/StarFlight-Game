## Game Features 🎯

- **Endless Runner Gameplay**: Navigate a glowing star through a space tunnel
- **Tap to Fly**: Simple one-finger control - tap to rise, gravity pulls down
- **Avoid Obstacles**: Navigate around asteroids and black holes
- **Collect Coins**: Gather coins to unlock upgrades
- **Upgrade System**: Buy permanent upgrades:
  - ⚡ **Speed** - Move faster
  - 🛡️ **Shield** - One-hit protection
  - 🧲 **Magnet** - Auto-collect nearby coins
  - 🚀 **Boost** - Temporary speed burst

- **Persistent Progress**: Your coins and upgrades are saved automatically
- **Beautiful Graphics**: Neon space aesthetic with smooth animations
- **Mobile Optimized**: Works seamlessly on iOS and Android

## Installation Guide

### Android (Easiest)
1. **Download** the APK file from the link above
2. **Open** the file on your Android device (it will download to Downloads folder)
3. **Allow unknown sources** (if prompted in Settings)
4. **Tap Install** and wait for completion
5. **Open** the app from your home screen

### iOS
1. **Download** TestFlight app from App Store (if you don't have it)
2. **Open** the TestFlight link above
3. **Accept** the invite
4. **Install** StarFlight from TestFlight
5. **Play!**

### Windows
1. **Download** the EXE installer
2. **Double-click** the file
3. **Click Install** (if Windows SmartScreen appears, click "Run anyway")
4. **Wait** for installation to complete
5. **Play!**

### Mac
1. **Download** the DMG file
2. **Double-click** to mount the disk image
3. **Drag** the StarFlight app to Applications folder
4. **Open** Applications and double-click StarFlight
5. **Play!**

## How to Play 🎮

1. **Tap the screen** (mobile) or **click** (desktop) to make the star rise
2. **Avoid** the red obstacles
3. **Collect** yellow coins
4. **Survive** as long as possible to increase your score
5. **Earn coins** to buy upgrades between runs
6. **Upgrade** your abilities to survive longer

### Controls
- **Mobile**: Tap anywhere on screen
- **Desktop**: Click anywhere or press SPACEBAR
- **Pause**: Tap/click the pause button (top-left)

## Troubleshooting 🔧

### App won't install on Android
- **Solution**: Go to Settings > Security > Enable "Unknown Sources"
- Make sure you have at least 100 MB free space

### iOS installation issues
- **Solution**: Make sure you're using TestFlight app
- Check that you've accepted the invite
- Try reinstalling TestFlight from App Store

### Game runs slowly
- **Solution**: Close other apps running in background
- Restart your device
- Update to the latest game version

### Lost my progress
- **Solution**: Progress is saved automatically
- If you deleted the app, progress is lost
- Always reinstall from the same link to keep progress
